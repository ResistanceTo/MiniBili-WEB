# MiniBili 主题包

MiniBili 的「设置 → 主题与背景 → 主题包」可以填一个 JSON 清单地址，
App 会下载里面的图标并**永久缓存到本地**，之后不再联网，离线也能正常显示。

## 清单格式

```json
{
  "name": "猫猫狗狗",
  "version": 1,
  "icons": {
    "home": "https://example.com/home.png"
  }
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | 否 | 包名，显示在设置页 |
| `version` | 否 | 版本号，每次更新内容时递增 |
| `icons` | 否 | 入口 → 图片地址。键见下表 |

`icons` 可以只写一部分，没写到的入口保持原样。**无法识别的键会被静默忽略**，
所以可以为将来的入口预留条目，不会导致整个包解析失败。

## 入口键名

| 键 | 对应入口 |
|---|---|
| `home` | 首页 |
| `dynamic` | 动态 |
| `category` | 分区 |
| `history` | 历史记录 |
| `favorite` | 收藏 |
| `watchLater` | 稍后再看 |
| `subscription` | 订阅 |
| `message` | 消息 |
| `downloads` | 下载 |

底部菜单只能同时显示三个可配置入口，但九个都可以先把图标设好——
图标跟随入口本身，把它换到底部菜单时会自动带上。

## 图片要求

- **只支持 https**
- 建议**正方形**、200×200 以上。图标最终会画到 28pt，非正方形的图等比缩小居中后会显得很小
- **带透明背景的 PNG 效果最好**：会完整保留原始形状
- 不含透明区域的图片会被自动裁剪成圆形，与「我的」头像保持一致
- 单张不超过 5MB，清单不超过 64KB

## 更新

用户在设置页点「检查更新」时会重新下载清单和图标。

⚠️ 更新内容时建议**换文件名**（例如 `home-v2.png`）并递增 `version`，
不要原地替换同名文件——CDN 缓存可能让用户拿到旧图。

「检查更新」**不会覆盖**用户手动上传过的入口，那属于用户自己的选择。

## 示例

`pets/pack.json` 是一个完整可用的示例包：

```
https://minibili.zhaohe.org/themes/pets/pack.json
```
